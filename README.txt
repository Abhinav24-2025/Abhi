# Cutiee_Kitttuuu 🌻

A self-contained Horn-OK-Please-inspired ghazal playlist page.

## Run locally
Open `index.html` in a browser while connected to the internet. The player uses the YouTube IFrame API and your YouTube playlist:
PLt3Ip3iAiQF955awVaawhCJ9GfbBu6rDN

## Publish/share
Upload the contents of this folder to any static hosting service (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.). Keep the `assets` folder beside `index.html`.

Note: browsers may require the first Play click because of autoplay restrictions.
